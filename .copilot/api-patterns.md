# CQRS API Patterns and Guidelines

## CQRS Architecture Overview

The Blueprint framework enforces **Command Query Responsibility Segregation (CQRS)** to separate read and write operations with clear boundaries and different optimization strategies.

### Core CQRS Interfaces

```csharp
// Base operation marker
public interface IOperation
{
    static abstract ApiOperationDescriptor Configure(); // Generated by source generator
}

// Read operations (Queries)
public interface IQuery : IOperation { }
public interface IQuery<TResponse> : IQuery, IReturn<TResponse> { }

// Write operations (Commands) 
public interface ICommand : IOperation { }
public interface ICommand<TResponse> : ICommand, IReturn<TResponse> { }

// Response type specification
public interface IReturn<TResponse> { }
```

## Query Patterns (Read Operations)

### Basic Query Pattern
```csharp
/// <summary>
/// Retrieves all templates available to the current user.
/// </summary>
[MustBeAuthenticated]
[SelfLink(typeof(TemplateListApiResource), "/templates")]
[HttpGet]
public partial class GetTemplatesQuery : IQuery<TemplateApiResource[]>
{
    // Optional: Query parameters
    public string? CategoryFilter { get; set; }
    public int PageSize { get; set; } = 20;
    public int PageNumber { get; set; } = 1;
    
    // Note: Configure() method is generated automatically
}
```

### Parameterized Query Pattern
```csharp
/// <summary>
/// Retrieves a specific template by its unique identifier.
/// </summary>
[MustBeAuthenticated]
[SelfLink(typeof(TemplateApiResource), "/templates/{id}")]

{
    /// <summary>
    /// The unique identifier of the template to retrieve.
    /// </summary>

```

### Complex Query with Multiple Filters
```csharp
/// <summary>
/// Searches templates with advanced filtering and sorting options.
/// </summary>
[MustBeAuthenticated]
[SelfLink(typeof(TemplateSearchResultsApiResource), "/templates/search")]
[HttpGet]
public partial class SearchTemplatesQuery : IQuery<TemplateSearchResultsApiResource>
{
    public string? SearchTerm { get; set; }
    public string? Category { get; set; }
    public string? Tag { get; set; }
    public DateTime? ModifiedAfter { get; set; }
    public TemplateSortOrder SortBy { get; set; } = TemplateSortOrder.Name;
    public SortDirection Direction { get; set; } = SortDirection.Ascending;
    public int PageSize { get; set; } = 20;
    public int PageNumber { get; set; } = 1;
}

public enum TemplateSortOrder
{
    Name,
    CreatedDate,
    ModifiedDate,
    Category
}

public enum SortDirection
{
    Ascending,
    Descending
}
```

## API Resource Patterns

### Basic Resource Pattern
```csharp
/// <summary>
/// Represents a template resource in the API.
/// </summary>
public partial class TemplateApiResource : ApiResource
{
    // Private constructor for JSON deserialization
    private TemplateApiResource() { }
    
    /// <summary>
    /// Initializes a new instance of the template resource.
    /// </summary>
    public TemplateApiResource(
        string id, 
        string name, 
        string content, 
        string category)
    {
        this.Id = id;
        this.Name = name;
        this.Content = content;
        this.Category = category;
    }
    
    /// <summary>
    /// The unique identifier of the template.
    /// </summary>
    public string Id { get; private set; } = null!;
    
    /// <summary>
    /// The name of the template.
    /// </summary>
    public string Name { get; private set; } = null!;
    
    /// <summary>
    /// The HTML content of the template.
    /// </summary>
    public string Content { get; private set; } = null!;
    
    /// <summary>
    /// The category this template belongs to.
    /// </summary>
    public string Category { get; private set; } = null!;
    
    /// <summary>
    /// Optional description of the template.
    /// </summary>
    public string? Description { get; private set; }
    
    /// <summary>
    /// Tags associated with this template.
    /// </summary>
    public string[] Tags { get; private set; } = Array.Empty<string>();
    
    /// <summary>
    /// When this template was created.
    /// </summary>
    public DateTime CreatedAt { get; private set; }
    
    /// <summary>
    /// When this template was last modified.
    /// </summary>
    public DateTime? ModifiedAt { get; private set; }
}
```

### Collection Resource Pattern
```csharp
/// <summary>
/// Represents a paginated collection of templates.
/// </summary>
public partial class TemplateListApiResource : ApiResource
{
    private TemplateListApiResource() { }
    
    public TemplateListApiResource(
        TemplateApiResource[] templates,
        int totalCount,
        int pageNumber,
        int pageSize)
    {
        this.Templates = templates;
        this.TotalCount = totalCount;
        this.PageNumber = pageNumber;
        this.PageSize = pageSize;
    }
    
    /// <summary>
    /// The templates in this page.
    /// </summary>
    public TemplateApiResource[] Templates { get; private set; } = null!;
    
    /// <summary>
    /// Total number of templates available.
    /// </summary>
    public int TotalCount { get; private set; }
    
    /// <summary>
    /// Current page number (1-based).
    /// </summary>
    public int PageNumber { get; private set; }
    
    /// <summary>
    /// Number of items per page.
    /// </summary>
    public int PageSize { get; private set; }
    
    /// <summary>
    /// Whether there are more pages available.
    /// </summary>
    public bool HasNextPage => this.PageNumber * this.PageSize < this.TotalCount;
    
    /// <summary>
    /// Whether there are previous pages available.
    /// </summary>
    public bool HasPreviousPage => this.PageNumber > 1;
}
```

## Best Practices Summary

### Operation Design
- **Single Responsibility**: Each operation should have one clear purpose
- **Immutable Data**: Use readonly properties with private setters
- **Validation**: Apply data annotations for input validation
- **Documentation**: Provide XML comments for all public APIs

### Resource Design  
- **Consistent Naming**: Follow `{Entity}ApiResource` pattern
- **Private Constructors**: Include parameterless constructor for JSON
- **Computed Properties**: Add calculated fields like `HasNextPage`
- **Temporal Data**: Include created/modified timestamps

### Route Design
- **RESTful**: Follow REST conventions for predictability
- **Hierarchical**: Use sub-resources for related data
- **Descriptive**: Use clear, meaningful route segments
- **Consistent**: Maintain consistent patterns across resources

### Link Relationships
- **Self Links**: Always provide self-identification
- **Related Resources**: Link to associated data
- **Actions**: Expose available operations
- **Context-Aware**: Include relevant links based on state
